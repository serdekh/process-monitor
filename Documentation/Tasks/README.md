## Navigation

Every task belongs into one of the following groups:

- [**_Closed_**](./Closed.md)
  - Marks completed tasks.

- [**_InProcess_**](./InProcess.md)
  - Contains the tasks which are currently being worked on.

- [**_Open_**](./Open.md)
  - Contains the ideas for the future and the issues.
